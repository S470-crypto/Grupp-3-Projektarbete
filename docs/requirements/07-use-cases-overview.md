## 7. Use Cases Overview

# 7.1 Aktörer

|  Aktör | Beskrivning |
|--------------|-------|
| Spelare | Använder systemet för att starta och spela spel mot en vän eller datorn. |
| Motståndare | Den andra spelaren (mänsklig) som deltar i samma parti via inbjudningslänk. |
| AI | Spelar automatisk mot spelaren och gör drag enlig spelets regler. |
| Administratör | Hanterar användare, behörigheter och tekniska problem. |
| Dataansvarig | Ansvarar för GDPR, dataradering och personuppgiftsincidenter. |
| Systemet | Kontrollerar drag och hanterar sparade och inaktiva spel. |
