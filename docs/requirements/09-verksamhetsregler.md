# 9. Verksamhetsregler




## VR-01: Spelregler

| ID | Regler |
|----|------|
| VR-01.1 | Ett parti spelas mellan två spelare (en vän och en datorn/AI). |
| VR-02.2 | En spelare får endast placera en bricka på en ledig spelruta. |
| VR-03.3 | Spelarna ska turas om att göra ett drag. |
| VR-04.4 | En spelare får inte ändra eller ta bort en bricka som har redan placerad. |
| VR-05.5 | Ett drag ska tillhöras den spelare vars tur det är. |
| VR-06.6 | Det behövs inte att skapa konto för att starta parti för att spela. |
| VR-07.7 | Ett parti mellan två spelare ska kunna startas genom ett inbjudningslänk. |
| VR-08.8 | Endast två spelare får delta samtidigt i ett parti. |
| VR-09.9 | En tredje spelare får inte ansluta till ett parti som redan har två deltagare. |
| VR-10.10 | Inbjudningslänk är endast giltig under den angivna giltighetstiden (5 minuter). |
| VR-11.11 | Ett parti som inte längre är aktivt ska inte kunna försätta spelas. |
| VR-12.12 | Efter att ett parti har avslutat ska spelarna kunna starta ett nytt parti. |
