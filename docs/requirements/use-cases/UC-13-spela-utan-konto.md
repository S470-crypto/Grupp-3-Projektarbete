## USE CASE: UC-13 Spela utan konto


**Meta**


**Use case:** Spela utan konto

**Use case ID:** UC-09

**Primär Aktör:** Spelare

**Syfte:** Spelaren vill kunna spela utan att skapa konto eller logga in.


## Förutsättningar:

Spelaren har öppnat spelet och har tillgång till spelets startsida.

## Trigger:

Spelaren väljer att starta ett spel utan konto eller logga in


## Huvudföde:

1. Spelaren öppnar spelet (Gomoku)
2. Systemet visar att spela utan konto eller logga in med konto
3. Spelaren väljer Spela utan konto
4. Systemet startar spelet utan registrering eller inloggning
5. Spelaren kan börja spela Gomoku utan konto


## Postcondition:

* Spelaren startat spelet och kan spela Gomoku utan konto eller behöver inte att logga in.


## Testbar avslutning:

* Spelaren kan starta och spela utan att logga in eller skapa ett konto.
